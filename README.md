# thedobraquiz

Quiz responsivo de maturidade em análise de dados para empresas, com a identidade visual da TheDobra.

Inclui 10 perguntas, diagnóstico em cinco dimensões, recomendações personalizadas e contato com a TheDobra.

## Executar localmente

```sh
cd quiz
node server.cjs
```

Acesse http://127.0.0.1:4173.

## Publicação

Publique os arquivos da pasta `quiz/dist` em uma hospedagem estática. Não é necessário build nem banco de dados.

Veja [a documentação do quiz](quiz/README.md) para detalhes sobre a pontuação e o tratamento das respostas.
